# Portuguese classes site

A simple one-page Next.js site.

## Run it locally (optional, to preview before deploying)

```
npm install
npm run dev
```

Then open http://localhost:3000

## Get it live on Vercel (free)

1. Create a free account at https://vercel.com (sign up with GitHub — easiest).
2. Create a new, empty repository on https://github.com/new and push this folder to it.
3. In Vercel, click "Add New" → "Project", and import that GitHub repository.
4. Leave all settings as default (Vercel auto-detects Next.js) and click "Deploy".
5. After a minute or two, Vercel gives you a live URL like `portugues-site.vercel.app`.

That's it — no custom domain needed yet. You can add one later once you decide on it.
